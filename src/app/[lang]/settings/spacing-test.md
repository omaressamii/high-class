# اختبار ميزة المسافات بين عناصر الباركود / Barcode Element Spacing Feature Test

## نظرة عامة / Overview

تم إضافة ميزة جديدة لتخصيص المسافات بين عناصر الباركود في صفحة الإعدادات.

A new feature has been added to customize spacing between barcode elements in the settings page.

## التغييرات المطبقة / Applied Changes

### 1. تحديث واجهة البيانات / Data Interface Updates
- إضافة خاصية `spacing: number` إلى واجهة `BarcodeSettings`
- تحديث القيم الافتراضية لتشمل `spacing: 2`
- تحديث جميع الملفات المرتبطة لدعم الخاصية الجديدة

### 2. تحديث واجهة المستخدم / UI Updates
- إضافة حقل إدخال جديد للمسافات في صفحة الإعدادات
- إضافة نصوص الترجمة للعربية والإنجليزية
- إضافة نص توضيحي للمساعدة

### 3. تحديث المعاينة / Preview Updates
- تحديث مكون `BarcodePreview` لاستخدام المسافات الديناميكية
- تطبيق المسافات على جميع عناصر الباركود (اسم الشركة، اسم المنتج، الباركود، الرقم، السعر)

### 4. تحديث الطباعة / Print Updates
- تحديث مكون `PrintBarcodeButton` لاستخدام المسافات في الطباعة
- تطبيق المسافات على CSS للطباعة

## القيم المتوقعة / Expected Values

### القيم الافتراضية / Default Values
```typescript
{
  width: 3.5,
  height: 70,
  fontSize: 12,
  margin: 5,
  spacing: 2,  // جديد / New
  containerWidth: '4cm',
  containerHeight: '2.5cm'
}
```

### نطاق القيم / Value Range
- الحد الأدنى: 0 بكسل (بدون مسافات)
- الحد الأقصى: 10 بكسل (مسافات كبيرة)
- القيمة الافتراضية: 2 بكسل (مسافات متوسطة)
