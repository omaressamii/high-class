# دليل اختبار صفحة الإعدادات / Settings Page Testing Guide

## خطوات الاختبار / Testing Steps

### 1. اختبار الوصول / Access Testing
- [ ] تسجيل الدخول بحساب له صلاحية `users_manage`
- [ ] التأكد من ظهور رابط "الإعدادات" في القائمة الرئيسية
- [ ] النقر على رابط الإعدادات والتأكد من فتح الصفحة
- [ ] اختبار الوصول بحساب بدون صلاحية والتأكد من عدم ظهور الرابط

### 2. اختبار إعدادات الباركود / Barcode Settings Testing

#### تحميل الإعدادات / Loading Settings
- [ ] التأكد من تحميل الإعدادات الافتراضية عند أول زيارة
- [ ] التأكد من تحميل الإعدادات المحفوظة مسبقاً

#### تعديل الإعدادات / Modifying Settings
- [ ] تغيير عرض الباركود (1-5) والتأكد من التحديث في المعاينة
- [ ] تغيير ارتفاع الباركود (40-100) والتأكد من التحديث في المعاينة
- [ ] تغيير حجم الخط (8-16) والتأكد من التحديث في المعاينة
- [ ] تغيير الهامش (0-10) والتأكد من التحديث في المعاينة
- [ ] تغيير المسافات بين العناصر (0-10) والتأكد من التحديث في المعاينة
- [ ] تغيير أبعاد الحاوية والتأكد من التحديث في المعاينة

#### حفظ الإعدادات / Saving Settings
- [ ] النقر على "حفظ الإعدادات" والتأكد من ظهور رسالة النجاح
- [ ] إعادة تحميل الصفحة والتأكد من حفظ الإعدادات
- [ ] النقر على "إعادة تعيين افتراضي" والتأكد من العودة للقيم الافتراضية

### 3. اختبار معاينة الباركود / Barcode Preview Testing
- [ ] التأكد من ظهور معاينة الباركود بشكل صحيح
- [ ] التأكد من تحديث المعاينة عند تغيير أي إعداد
- [ ] التأكد من عرض ملخص الإعدادات الحالية
- [ ] التأكد من عرض النصوص بالعربية والإنجليزية حسب اللغة المختارة

### 4. اختبار الإعدادات العامة / General Settings Testing

#### تحميل الإعدادات / Loading Settings
- [ ] التأكد من تحميل الإعدادات الافتراضية
- [ ] التأكد من تحميل الإعدادات المحفوظة مسبقاً

#### تعديل الإعدادات النصية / Text Settings
- [ ] تغيير اسم الشركة (إنجليزي) والتأكد من الحفظ
- [ ] تغيير اسم الشركة (عربي) والتأكد من الحفظ
- [ ] تغيير العملة الافتراضية والتأكد من الحفظ

#### تعديل الإعدادات الرقمية / Numeric Settings
- [ ] تغيير فترة النسخ الاحتياطي (1-168) والتأكد من الحفظ
- [ ] تغيير عدد الطلبات لكل صفحة (10-100) والتأكد من الحفظ
- [ ] تغيير عدد المنتجات لكل صفحة (10-100) والتأكد من الحفظ

#### تعديل الإعدادات المنطقية / Boolean Settings
- [ ] تفعيل/إلغاء النسخ الاحتياطي التلقائي والتأكد من الحفظ
- [ ] تفعيل/إلغاء الإشعارات والتأكد من الحفظ

### 5. اختبار التكامل / Integration Testing

#### اختبار طباعة الباركود / Barcode Printing Test
- [ ] الانتقال إلى صفحة منتج
- [ ] النقر على "طباعة الباركود"
- [ ] التأكد من استخدام الإعدادات المحفوظة في الطباعة
- [ ] مقارنة الباركود المطبوع مع المعاينة في صفحة الإعدادات

### 6. اختبار الاستجابة / Responsive Testing
- [ ] اختبار الصفحة على الهاتف المحمول
- [ ] اختبار الصفحة على الجهاز اللوحي
- [ ] اختبار الصفحة على الحاسوب المكتبي
- [ ] التأكد من عمل جميع الأزرار والحقول على جميع الأحجام

### 7. اختبار معالجة الأخطاء / Error Handling Testing
- [ ] قطع الاتصال بالإنترنت ومحاولة حفظ الإعدادات
- [ ] إدخال قيم خارج النطاق المسموح والتأكد من التحقق
- [ ] اختبار سلوك التطبيق عند فشل تحميل الإعدادات

### 8. اختبار الأداء / Performance Testing
- [ ] قياس وقت تحميل الصفحة
- [ ] قياس وقت حفظ الإعدادات
- [ ] التأكد من عدم وجود تسريبات في الذاكرة
- [ ] اختبار الصفحة مع بيانات كبيرة

## قائمة التحقق النهائية / Final Checklist

### الوظائف الأساسية / Core Functionality
- [ ] تحميل الإعدادات من قاعدة البيانات
- [ ] حفظ الإعدادات في قاعدة البيانات
- [ ] معاينة الباركود في الوقت الفعلي
- [ ] إعادة تعيين الإعدادات للقيم الافتراضية
- [ ] التحقق من صحة البيانات المدخلة

### تجربة المستخدم / User Experience
- [ ] واجهة سهلة الاستخدام
- [ ] رسائل واضحة للنجاح والخطأ
- [ ] تصميم متجاوب مع جميع الأحجام
- [ ] دعم اللغتين العربية والإنجليزية
- [ ] تحميل سريع وسلس

### الأمان / Security
- [ ] التحقق من الصلاحيات قبل الوصول
- [ ] التحقق من صحة البيانات قبل الحفظ
- [ ] حماية من الهجمات الشائعة
- [ ] تسجيل العمليات المهمة
